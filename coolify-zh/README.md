# Coolify 控制台汉化脚本

给 Coolify v4 自托管面板换上中文界面，右下角有个按钮可以一键在中文和英文之间切换。

- 适配版本：**Coolify v4.5.0**（v4.4.x 的大部分界面也能用）
- 当前脚本版本：**1.0.2**
- 文件：[`coolify-zh.user.js`](coolify-zh.user.js)

安全方面的说明单独写在 [SECURITY.md](SECURITY.md)，装之前建议看一眼。

## 它会做什么、不会做什么

**会：**

- 把界面上的英文按钮、菜单、标题、提示换成中文；
- 把输入框里的灰色提示字、鼠标悬停提示换成中文；
- 在右下角放一个切换按钮，记住你选的是中文还是英文。

**不会：**

- 不发任何网络请求；
- 不读 cookie、登录令牌、环境变量的值；
- 不改你填写的任何内容，不点任何按钮，不改页面结构；
- 不翻译日志、终端、代码编辑器里的内容，也不翻译你的应用名、域名这些数据；
- 不会自己联网更新。

## 安装

需要先在浏览器里装一个用户脚本管理器，比如 **Violentmonkey（暴力猴）** 或 **Tampermonkey（油猴）**。

1. 打开 [`coolify-zh.user.js`](coolify-zh.user.js)，点 “Raw” 查看原文，全选复制。
2. 在脚本管理器里新建一个脚本，把原有内容全部删掉，粘贴进去。
3. **找到这一行，改成你自己的面板地址**：

   ```
   // @match        https://coolify.example.com/*
   ```

   比如你的面板是 `https://panel.mydomain.com`，就改成：

   ```
   // @match        https://panel.mydomain.com/*
   ```

   只改域名，末尾的 `/*` 要保留。不改的话脚本不会在你的面板上运行。
4. 保存，刷新 Coolify 页面。

### 想确认下载的文件没被改过

在 GitHub 上下载原文件后，算一下 SHA-256，和下面的值对比。注意要在**改 `@match` 之前**算：

```
319f18fb9e2a18d5948aaa6dff9efa535a93455bdb4876074647f9aa1fe3f461
```

```bash
# macOS / Linux
shasum -a 256 coolify-zh.user.js

# Windows PowerShell
Get-FileHash coolify-zh.user.js -Algorithm SHA256
```

## 用法

- 默认显示中文。
- 点右下角的圆形按钮，切换成英文；再点一次切回中文。你的选择会记在浏览器里，下次打开还是这个语言。
- 切到英文时，页面会还原成 Coolify 原本的英文，不需要刷新。

## 已知限制

- 只翻译了我们实际打开过的页面。没有数据就进不去的页面（比如数据库、Compose 服务、已开启的备份）可能还有英文。
- “新建资源”页里几百个第三方服务模板的介绍没有翻译，那是一本应用目录，翻了意义不大。
- 脚本是按“整句完全一样”来替换的。Coolify 升级后改了某句英文，那句就会变回英文，需要补词典。
- 品牌名、产品名（Docker、Traefik、Cloudflare 等）保持英文。

发现漏翻或翻错的地方，欢迎提 Issue，最好附上截图和那句英文原文。
