# 05 域名和 DNS

在域名商那里加**一条通配符记录**，以后所有子域名都自动指向新服务器，不用每部署一个服务就回来加一次。

## 在哪买域名

我们用的是 Spaceship（记得查促销码），下面的步骤也是照着 Spaceship 的界面写的。用别家域名商也一样，找到 DNS 记录（DNS 管理）页面，加的东西完全相同。买的时候顺手做两件事：

- 打开**隐私保护**，不然你的注册信息会被公开查到；
- 打开**自动续订**，并确认扣款方式能用。

## 加 DNS 记录

Spaceship：域名管理器 → 点域名 → 最下面的**高级 DNS** → 添加记录。右边那个“连接”按钮是推销自家服务的，别点。

| 格子 | 填什么 |
|---|---|
| 类型 | A |
| 主机 | `*`（一个星号） |
| 值 | 新服务器的 IP |
| 生存时间（TTL） | 搬家期间选短的，比如 5 到 20 分钟，改了生效快 |

两个要注意的地方：

- **通配符只管一层。** `api.你的域名.com` 可以，`www.api.你的域名.com` 不行。
- **根域名不包含在内。** `你的域名.com` 本身要单独加一条主机为 `@` 的 A 记录，如果你打算用它的话。

**确认生效**：在服务器上粘

```bash
getent hosts coolify.你的域名.com
```

输出里有你的 IP 就是好了。

## 给面板挂域名

地址栏打开 `http://<新IP>:8000/settings`，在 **URL** 那格填 `https://coolify.你的域名.com`（要带 `https://`），保存。旁边 **Redirect HTTP to HTTPS** 保持 Enabled。时区想按北京时间显示，可以改成 `Asia/Shanghai`。

然后新开标签页打开这个地址，地址栏不再显示“不安全”就是证书申请好了，以后都用这个地址进面板。

**改完记得点保存。** Coolify 很多设置页改完要点页面上的“保存更改”，切走就丢。

## 每个服务的子域名

建议统一成 `服务名.你的域名.com`，好记。

也可以在 **Servers → localhost → General → Wildcard Domain** 填 `https://你的域名.com`，以后新建服务会自动生成一个子域名，不用手动填（名字是随机的，不好记）。

## 子域名不是秘密

每个子域名申请 HTTPS 证书时，都会被记进全网公开的证书透明日志，任何人都能查到你有哪些子域名。**不要指望“地址没人知道”来保护服务**，没有鉴权的服务不要挂域名，详见第 06 步的“只给内网用的服务”和第 08 步。

## 顺手检查

域名商那里的**自动续订**有没有开。域名过期，挂在上面的所有服务一起失效。
