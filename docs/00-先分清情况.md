# 00 先分清你是哪种情况

如果你的服务器是在 Zeabur 后台直接买的，**到期后整台机器连同硬盘一起被删，数据不保留**，所以必须另买一台新服务器，把东西搬过去。这份指南就是写给这种情况的。

| 你的情况 | 机器到期后 | 要怎么搬 |
|---|---|---|
| **在 Zeabur 后台买的专用服务器** | 属于 Zeabur 的云账号，到期关机并删除，硬盘不保留 | 另买新服务器（本指南用 HostHatch），从旧机备份数据，到新机重新部署 |
| 自己的服务器绑定到 Zeabur | 机器还是你的，只是 Zeabur 装的组件失效 | 可以备份后原地重装，也可以另买 |
| 共享集群（没有自己的服务器） | 服务暂停，之后停止 | 没有 SSH，只能用 Zeabur 提供的方式导出数据。官方说 12 月 1 日后暂停的服务还能手动恢复来备份，**尽早做**。不在本指南的详细范围内，但第 03 步的备份原则同样适用 |

好消息是：你是“另买一台”，所以**旧机在到期前一直能用**。新机搭好、测通了再切过去，中途出问题随时退回旧机，这是原地重装没有的退路。

## 要用到的东西

整个搬家只用到下面这几样，除了服务器和域名，其他都免费。

| 东西 | 干什么用 | 备注 |
|---|---|---|
| **HostHatch** | 新服务器 | 后台叫 Servers；重装、快照、控制台都在服务器详情页 |
| **Termius** | 在电脑或手机上 SSH 登录服务器、粘命令、传文件（SFTP） | 免费版够用；免费版不能开端口隧道（Tunneling），也不能用代理 |
| **Coolify** | 新服务器上的部署面板，代替 Zeabur | 开源，自带 Traefik 反向代理和自动 HTTPS；原版全英文，可以装本仓库的[汉化脚本](../coolify-zh/)。猫猫表示：待定！找到更好的会替换 |
| **域名商**（比如 Spaceship） | 买域名、加 DNS 记录 | 没有域名也能用，但强烈建议买一个，以后换平台只改 DNS |
| **GitHub** | 放代码，Coolify 从这里拉代码自动部署 | 要装一个 GitHub App 给 Coolify |
| **一个能操作电脑的 agent** | 帮你盘点旧服务器、打包备份、下载、核对、生成环境变量文件 | 比如 Claude Code，换别的 agent 也行，要求是能在你电脑上跑命令、能 SSH |
| **一个聊天助手** | 看截图、解释每个按钮、陪你一步步做 | 猫猫用的是 Claude |

## 备用代理

如果你平时用的代理就搭在这台 Zeabur 服务器上，**搬家前先准备好另一个能用的代理**。旧机关掉那一刻，你可能连 agent 和 GitHub 都连不上。

## 两条贯穿全程的规矩

1. **先说再动手。** 不管是你自己还是 agent，每一步改动前先说清楚要做什么。
2. **密钥不进对话。** 密码、token、API key 不贴进任何聊天窗口；环境变量由你自己粘贴到 Coolify 里。
