# 踩坑合集

我们搬家时实际踩过的坑。

## 一览

| 坑 | 怎么回事 | 怎么办 |
|---|---|---|
| 买的 100G 只剩 85G | 商家按 1000 进制，系统按 1024 进制，再扣分区和文件系统 | 正常，`lsblk` 能看到整盘是 93.2G |
| Coolify 服务器显示 Attention required | 装完代理默认是停着的 | Servers → localhost → Start Proxy |
| 服务跑起来了外面连不上 | Coolify 默认端口 3000，服务实际听 8080 | Ports exposes 和域名的 Port 都改成实际端口 |
| 数据库连不上 | 环境变量值带了引号 | Developer view 里不要加引号 |
| 环境变量的值被改掉了一截 | 值里有 `$` 被当成变量引用；或有“空格 + #”被当成注释 | 带 `$` 的改成 Literal；密钥别用 `$`、空格、`#` |
| 后台名字和服务器上对不上 | 服务器上是编号和最初的项目名 | 用域名或环境变量里的地址去认 |
| QQ 机器人恢复后不说话 | 换了 IP，登录状态作废 | 远程桌面扫码重新登录 |
| GitHub App 看不到某个仓库 | 那个仓库在别人账号下，你只是协作者 | 公开仓库按公开仓库部署，或 fork |
| 快照用不了 | 部分机房不支持快照 | 以备份为准，别指望快照 |
| 用 ufw 关了端口，外面还是能访问 | Docker 发布的端口会绕过 ufw | 用服务器商控制台的防火墙，或 DOCKER-USER 链（第 04 步）；自己的容器端口绑 `127.0.0.1` |
| 代理的 8080 也开在公网上 | 代理容器把 Traefik 的 API 端口发布出来了，官方防火墙表里没列 | 一起拦掉，并确认代理配置里没开 `--api.insecure=true`（第 04 步） |
| 端口明明拦了，测出来还能打开 | 手机开着搭在这台服务器上的代理，请求从服务器自己身上绕回来，没经过外网口 | 关掉代理，用手机流量测 |
| 防火墙规则越粘越多 | 分几次粘，同一条规则加了两遍 | 加完 `--line-numbers` 数一遍；删重复按编号从大往小删；开机脚本用“已有就跳过”的写法（第 04 步） |
| 机器人的正向接口一直开在公网 | 从旧平台照搬的配置里开着 OneBot 正向服务端，实际用的是反向连接 | 用不到就关掉或拦掉它的端口（第 08 步） |
| 内网服务能从公网打开 | Coolify 新建服务会自动生成一个 sslip.io 公网地址 | 到 Domains 删掉它，删时别勾“删除 DNS 记录” |
| 填了域名但一直打不开 | 我们的一次原因：域名少打了 `.com` | 逐字核对，前面带 `https://` |
| 设置改了却没生效 | 设置页改完没点“保存更改” | 改完看一眼有没有“有尚未保存的更改”提示 |
| 在 Coolify 点了“停止”，容器就没了 | 停止时 Coolify 会删掉已退出的容器 | 往卷里放数据直接对卷操作（第 06 步） |
| 某天早上界面变了 | Coolify 默认每天自动更新 | 能接受就留着；想稳定就在 设置 → 更新 里关掉 |
| 往 main 推了一下，线上就变了 | 连了 GitHub App 后推送会自动部署 | 改动先在别的分支上做 |
| `www.api.你的域名.com` 打不开 | 通配符记录只管一层 | 单独加记录，或别用两层 |
| `你的域名.com` 本身打不开 | 通配符不包含根域名 | 单独加一条主机为 `@` 的 A 记录 |
| 旧机一关，连 GitHub 都上不去了 | 平时用的代理搭在旧机上 | 搬家前先准备好另一个代理 |
| Termius 连不上 | 主机设置里留着以前填的代理，免费版又用不了代理 | 清掉代理直连，或用系统自带的 `ssh` |
| Termius 提示 fingerprint changed | 服务器重装过，系统换了 | 点 Replace，不是被攻击 |

## 展开说两个

### 图床的图片突然全部打不开

我们的图片存在七牛云，用的是它给的测试域名，测试域名到期后就不能用了。换成用 S3 接口签名取图虽然能显示，但从对象存储往外取图要按流量收费，没有免费额度；绑自己的域名又要备案。权衡之后先停了图床，图片还留在七牛的空间里。

**教训**：用对象存储之前，先看清楚**外网流出流量**怎么收费、免费的测试域名能用多久。

### 以为别人不知道我的子域名

HTTPS 证书会进公开的证书透明日志，任何人都能查到你申请过哪些子域名。在 Zeabur 上那串随机地址相当于“藏起来的门”，换成好记的子域名就等于挂上了门牌。**靠鉴权保护服务，不靠地址保密。**
