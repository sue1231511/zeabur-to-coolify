# 07 换地址

服务在新机跑起来以后，所有指向旧地址的地方都要改。`*.zeabur.app` 域名在 Zeabur 关停后会失效，`.zeabur.internal` 内部地址换了平台就不存在了。

**顺序**：先部署被依赖的服务，再改调用它的地方。不然地址改过去了，那头还没人接。

| 地方 | 怎么改 |
|---|---|
| Telegram 机器人 | webhook 要指向新域名。如果你的代码是启动时按环境变量自动注册的，改环境变量重新部署就行；不是的话，用 Bot API 的 `setWebhook` 重新设一次（token 别贴进聊天） |
| QQ 机器人（比如 SnowLuma / NapCat） | 改它配置文件里连网关的地址，比如 `wss://网关域名/qq-ws`。换了服务器 IP，QQ 大概率要**重新扫码登录**，要用远程桌面（noVNC）看登录界面，扫码用机器人那个号 |
| 微信（iLink 之类） | 给机器人发一条消息，刷新会话就恢复了 |
| claude.ai 的 MCP 连接器 | 设置 → Connectors，把地址换成新域名，**域名后面的路径保持不变**（`/mcp` 或 `/sse`）。有 OAuth 的会让你重新授权 |
| 代码里写死的地址 | 让 agent 把仓库搜一遍 `zeabur`、`.zeabur.app`、`.zeabur.internal`，列出来再改。建议改成从环境变量读，以后再搬只改变量（提示词见[模板](12-给agent的提示词.md)第 4 段） |
| 环境变量里的地址 | `*_HOST`、`*_URL` 这类，值里有 zeabur 地址的逐个改 |
| 数据库里存的地址 | 比如模型供应商的 `base_url`、图片链接。用 SQL 搜一遍：`where 列名 ilike '%zeabur%'` |
| 小程序、前端 | 用相对路径的会自动跟着新域名走；写死了域名的要改 |

## 远程桌面怎么开才安全

QQ 机器人这类容器的远程桌面端口（比如 5900、6081）建议**只绑 `127.0.0.1`**，不开到公网。要扫码时走 SSH 隧道：

```bash
# 在你自己电脑上执行，把服务器的 6081 映射到本机的 6081
ssh -L 6081:127.0.0.1:6081 root@<新IP>
```

保持这个窗口开着，然后在浏览器打开 `http://127.0.0.1:6081/vnc.html`。

Termius 免费版不能开隧道，可以用 Windows 自带的 ssh（PowerShell 里直接输上面的命令），或者让 agent 帮你开一条。

## 全部改完再验收

每个机器人发一句话、每个连接器调一次、看一眼网关日志有没有报错。
