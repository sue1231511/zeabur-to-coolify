# 01 买新服务器

买一台装 **Ubuntu 24.04** 的服务器，记下 IP 和 root 密码，用 Termius 能登进去，这一步就完成了。

## 配置怎么选

Coolify 本身不大，装完大约占 2.4G 镜像，整盘用 4.3G 左右。真正吃资源的是你要跑的服务。参考：

- **内存**至少 4G，服务多（十几个以上）建议 8G 以上。每次部署还要在本机构建镜像，构建时内存和 CPU 会冲高。
- **硬盘**至少 40G。注意商家写的 100GB 换成系统里的单位只有 93G 左右，再扣掉分区，实际可用 85G 上下，这是正常的。
- **机房**选离你和你的用户近的；看一眼这个机房**支不支持快照**（Snapshots），比如 HostHatch 的洛杉矶机房就不支持。不支持快照，就更要做好第 03 步的备份。

Coolify 官方写的最低要求是 2 核、2GB 内存、10GB 硬盘，那是 Coolify 自己的需求，你的服务另算。

我们用的是 HostHatch 洛杉矶机房，只是自己用过，不是推荐。

## 装系统

下单时能选系统就直接选 Ubuntu 24.04。已经装了别的系统、或者想重装：在 HostHatch 服务器详情页的 Image 旁边有 **Reinstall**，或者 **Images** 标签下面的 **REINSTALL** 区域。

1. 点 **Ubuntu** 卡片，版本选 **24.04 x64**（22.04 也行，Coolify 两个都支持）
2. **上面的 MOUNT ISO 别碰**，那是挂安装光盘，要你在控制台手动装系统
3. SSH KEYS 那块可以跳过，用密码登录就行
4. 勾上“我明白重装会丢失所有数据”，点 **Reinstall Server**
5. **右上角的 Terminate 千万别点**，那是退租删机器

## 登录

1. 回到 **Details** 页，点 ROOT PASSWORD 旁边的复制按钮
2. Termius 新建主机：IP、用户名 `root`、粘贴密码
3. 登进去后粘这两条，确认系统和硬盘：

```bash
cat /etc/os-release | head -3
df -h /
```

以后重装过一次，Termius 会提示“fingerprint changed（指纹变了）”，点 **Replace** 就行，这是因为系统换了，不是被攻击。

Termius 连不上时，看一眼主机设置里是不是留着以前填的代理：免费版用不了代理功能，清掉直连就好。用系统自带的 `ssh root@<新IP>` 也完全可以。
