# 08 安全和收尾

## 最要紧的一条：没有鉴权的服务不要挂到自己的域名上

在 Zeabur 上，服务地址是一串没人知道的随机名字，相当于把门藏起来了；换成 `git.你的域名.com` 这种好记的名字，门就挂了门牌。

而且**子域名不是秘密**：每个子域名申请 HTTPS 证书时，都会被记进全网公开的证书透明日志，任何人都能查到你有哪些子域名。所以：

- 每个服务（尤其是 MCP）部署前先确认它**有没有鉴权**。能读写 GitHub、数据库、个人记录这类私事的，必须有。
- 没有的先加。可以给 MCP 加上 OAuth（claude.ai 连接器第一次连会弹页面输密钥，之后自动续期）+ 固定密钥（其他程序在请求头带 `Authorization: Bearer 密钥`）。
- **没配密钥时要拒绝所有请求**，不能“没配就放行”。
- 日志里不要打出令牌、授权码、密码原文。
- 密钥用够长的随机串（比如 `openssl rand -base64 32`），或者 20 个字符以上、不跟别处重复的密码。别用 `$`、空格、`#`（第 06 步讲过，它们在环境变量里会出问题）。
- 实在没法加鉴权的，就不挂域名，只走内网（第 06 步“只给内网用的服务”）。

## 所有密钥都换新

Zeabur 出过安全事故（见官方公告），你所有服务的环境变量都在它那里存过。搬完以后，不管看起来有没有泄露，都按“已经泄露”处理：

- [ ] GitHub token、部署密钥
- [ ] 数据库密码、云数据库的 service key
- [ ] 各种机器人的 token（Telegram 等）
- [ ] 各家模型和第三方服务的 API key
- [ ] 你自己服务之间互相认证用的密钥
- [ ] 同一个密钥被几个地方共用的，换的时候顺便拆开，一处一个

顺序：**先在新家配上新密钥、确认服务正常，再去旧的地方把旧密钥作废。** 反过来做，服务会断。换完一个勾一个，别凭记忆。

## 端口收紧

- [ ] Coolify 面板挂上域名后，关掉 8000、6001、6002 和代理的 8080 的公网访问：用服务器商的防火墙，没有的话用 DOCKER-USER 链（做法见第 04 步“防火墙”）。**光用 ufw 关不掉**
- [ ] 你自己跑的容器，管理后台和远程桌面端口只绑 `127.0.0.1`
- [ ] 自己跑的机器人容器（比如 QQ 机器人），看一眼有没有开着**正向接口**（比如 OneBot 的正向 WebSocket / HTTP 服务端）。你的机器人如果是**反向**主动连网关的，正向接口根本用不到；开在公网上，谁连上谁就能用你的号收发消息。不用就在配置里关掉，或者拦掉它的端口。我们的就是从旧平台照搬配置带过来的，一直没注意
- [ ] 每个服务检查一遍：不该公开的，没有域名、没有 Port mappings、自动生成的 sslip.io 地址已删

**自查办法**：

1. 先在服务器上列出所有对外的端口（命令见第 04 步“动手之前”），逐个认一遍是谁的、该不该对外；
2. 再在你自己电脑或手机上（不是服务器上）用浏览器或 `curl` 访问 `http://<新IP>:端口`，能打开的就是开在公网上的。
3. **你的代理如果搭在这台服务器上，测之前先关代理**，不然请求从服务器自己身上绕回来，会误以为还开着。

## Coolify 自己的 API 和 MCP

Coolify 4.5.0 有 REST API 和 MCP 端点，默认都是关的（设置 → 高级 → API and MCP）。

- 用不上就别开。
- 要开的话，建令牌时只给需要的权限：只是想看看状态，给 Read 就够了；“Read sensitive data” 能看到环境变量里的密码，没必要别勾。
- 令牌设上过期时间，到期自动作废。
- 不用了就到 密钥与令牌 → API 令牌 里吊销，立刻失效。

## 清理

- [ ] 迁移时临时加的 SSH 公钥（新旧服务器 `~/.ssh/authorized_keys` 里多出来的那几行）
- [ ] 服务器上的临时备份目录（比如 `/root/restore/`）
- [ ] 你电脑上的备份：**留着**，但确认只在本机和 U 盘，没上网盘

## 服务器本身

- 系统内核更新后要重启才生效，挑没人用的时候重启一次。用了 DOCKER-USER 防火墙的，重启后 `iptables -L DOCKER-USER -n` 看一眼规则还在。
- 不要随手跑 `do-release-upgrade` 这类跨大版本升级，Coolify 和 Docker 可能会出问题。
- 记下服务器和域名的续费日期，提前提醒自己。

## 旧机怎么办

新机全部验收通过、最后一次同步也做完以后，旧机就可以让它自然到期了。在那之前它一直是你的退路，别急着删。
